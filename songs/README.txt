Put a song here for any day and it plays automatically that day after unlocking.
Name the file by the date:

  nov16.mp3  nov17.mp3  nov18.mp3 ... nov30.mp3  dec01.mp3

No file for a day?  -> plays song.mp3 from the main folder (if you add one),
                       otherwise "Ik Lamha" from YouTube.
No dec01.mp3?       -> on 1 December a built-in Happy Birthday tune plays.
